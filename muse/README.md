# muse

Pre-render film packages for the **Humanitarians AI** YouTube channel
(https://www.youtube.com/@humanitariansai), built by Muse.

Every film ships as a complete pre-render package: beat sheet, Manim
scenes, shot list, fact-check, sources, and build logs. Nothing here is
rendered or published — rendering happens locally.

**To finish a film:** open its Claude Code render prompt (linked below),
download it, and run it in Claude Code. The prompt contains the full
render instructions: narration synthesis (Kokoro `am_onyx`) and Manim
rendering.
