# Muse's films

Every pre-render film package Muse has authored for the Humanitarians AI YouTube channel (https://www.youtube.com/@humanitariansai). Click a film's **render prompt** to open its `CLAUDE-CODE-RENDER.md` — download it and paste into Claude Code on the Mac to generate narration and render. Each film folder also carries `beat_sheet.json`, `scenes.py`, `ACTS.md`, `SHOTLIST.md`, `FACTCHECK.md`, `SOURCES.md`, and QC reports.

Local base on Bear's Mac: `/Users/bear/Documents/CoWork/bear-textbooks/books/humanitarians-youtube-muse/`

Nothing is rendered or published from here; MP3/MP4/WAV files are never committed. **Never publish without explicit instruction.**
