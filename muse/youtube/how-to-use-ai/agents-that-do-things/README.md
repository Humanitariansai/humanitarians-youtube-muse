# Agents: AI that does things.

Pre-render package for the Humanitarians AI YouTube channel
(how-to-use-ai series). Channel `claude-liam` — Liam, in for Bear.
Kokoro `am_onyx`, Teardown register, watermark `@NikBearBrown`.

**Pitch:** What "agentic" AI means for a normal person — where it helps,
where it goes wrong, how to supervise it.

**Skill:** ai-explainer (as assigned).

**Package:** 12 beats, ~5m24s (324 s). 8 hand-authored Manim scenes
(B02–B09) + 4 Remotion bookend beats (ClaudeComposerAsk, hesitant-writer
BLUF, your-turn composer, locked title outro). No products named, no
prices quoted, no version-specific features asserted.

**Supervision framework (the film's spine):** delegate only what you can
check · approve anything irreversible · start on low stakes.
