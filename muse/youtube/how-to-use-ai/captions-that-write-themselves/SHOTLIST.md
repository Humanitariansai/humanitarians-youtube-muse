# SHOTLIST.md — Captions That Write Themselves

Scene table: scene → beat → what the viewer sees → data source.
House style: Manim, 16:9, safe area ±6.2 x / ±3.3 y, Claude palette
(stage #F2F0E9, ink #3D3929, terracotta #D97757, kraft cardboard faces).
Every on-screen word is read aloud in its beat. All body scenes are
original isometric Manim drawings — no cards, no screenshots, nothing
presented as a real interface. The bookends (BIDEA / BDEFS / BHTF /
BOUT) are the house Remotion patterns. Cast, kept whole film: the phone
video, caption lines, the dark AI block, the captioning tool, check
stamps.
