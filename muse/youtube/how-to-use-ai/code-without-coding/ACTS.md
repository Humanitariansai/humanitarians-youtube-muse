# ACTS — Code without coding

How-to-AI film · show-tell · 13 beats · ~248 s estimated.

## Bookends (house show-tell)

- **BIDEA — The question.** Hesitant writer. Liam greets ("Hallo. This is Liam,
  in for Bear."), types the naive request ("Write me an app that does
  everything") and corrects it into the film's thesis ("Write me an app that
  does one small thing"). The correction IS mistake one's lesson.
- **BDEFS — Terms in this film.** code / AI coding tool / bug, one line each.

## Body

- **Act 1 — The promise (B00).** The hero object: a finished page that does
  exactly what you asked for, arriving without you writing a line of code.
- **Act 2 — How it works (B01).** The pipeline: your words go into the tool,
  it writes the code, your page comes back. Code explained as a recipe the
  computer reads.
- **Act 3 — What's safe (B02–B03).** Two safety rules. First: build things you
  can check by looking (a page, a quiz, a tracker) — if you can see what's
  wrong, you can judge it. Second: keep it personal — only things that touch
  you and your stuff; passwords, payments, and other people's data are not a
  first project.
- **Act 4 — The three mistakes (B04–B06).** Mistake one: starting too big —
  the tower of pages topples; the fix is one small thing at a time. Mistake
  two: pasting secrets — the password card is blocked at the window; never
  paste what you wouldn't pin to a noticeboard. Mistake three: trusting
  without testing — the cursor clicks every button; the unclicked one hides
  the bug.
- **Act 5 — The loop (B07).** When something breaks: describe the problem back
  to the tool in plain words; it fixes the code; you check again. Describe,
  check, repeat.
- **Act 6 — Why now (B08).** The number, attributed: a quarter of Y
  Combinator's Winter 2025 batch shipped products on codebases that were
  ninety-five percent AI-written — the tools got that good.

## Bookends (close)

- **BHTF — Your turn.** Claude.ai composer: have the tool build one small page
  (a random name picker), show what each button does, add nothing unasked.
  Two self-checks: click every button; nothing private went in.
- **BOUT — Spoken outro.** "Code without coding. At Nik Bear Brown."
