# PROMPTS — Code without coding

No generation prompts. This film uses no AI-generated images, video, or audio
beds: every body beat is an original isometric Manim drawing (scenes.py, house
iso kit), the four bookends are Remotion patterns (BrutalistHesitantWriter,
ClaudeDefinitions, ClaudeComposerAsk, ClaudeTitleOutro), and the narration is
Kokoro `am_onyx` TTS rendered from the beat sheet's `narration_text` on Bear's
Mac. Nothing in this package requires a text-to-image or text-to-video model.
