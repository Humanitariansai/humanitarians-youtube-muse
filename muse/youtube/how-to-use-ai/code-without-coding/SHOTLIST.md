# SHOTLIST — Code without coding

One drawing per body beat (show-tell law 1). Labels are 1–3 words, ink, beside
objects. Cast carried through the film: the prompt card (white page), the AI
tool window (pale Claude window, grey title band), the working page, the
"password" name-tag, buttons, cursor, terracotta checks, ink crosses.

No ShowTellCard is used in this film: every body beat is a thing, a part, or a
flow (a page landing, cards springing up, a card bouncing off a ring, a tower
toppling, a cursor clicking), so each one fails the card test at step 1 — a
drawing of the film's own cast teaches it better. The four Remotion bookends
(BIDEA/BDEFS/BHTF/BOUT) are the house bookends, not cards.
