# FACTCHECK.md — "ChatGPT or Claude?" (general-audience redo)

Checked 2026-10-03 against live web sources (see SOURCES.md).
Verdicts: SUPPORTED / QUALIFY / UNSUPPORTED / DROPPED.

## 1. Version numbers in the source title — FLAGGED, film rewritten without them

The source beat sheet is titled "ChatGPT-5.5 or Claude 4.7?" and asserts
both as the current choice. What the press actually says:

- **GPT-5.5**: OpenAI announced it 2026-04-23 (CNBC, The Verge, Axios via
  Wikipedia's GPT-5.5 article). Multiple outlets (ts2.tech, startupfortune,
  mixed-news, chatgptaihub, Sept 2026) report OpenAI retiring GPT-5.5 from
  ChatGPT/ChatGPT Work/Codex on **2026-10-14** — eleven days after this
  film is built — with GPT-5.6 Sol/Terra/Luna as replacements.
- **"Claude 4.7"**: imprecise. Anthropic's model is **Claude Opus 4.7**
  (announced 2026-04-16 per SiliconANGLE, securitybrief, aibase). One
  Medium piece (2026-09-20) lists eight Claude releases in twelve months:
  Sonnet 4.5 → Sonnet 4.6 → Opus 4.7 → Opus 4.8 → Fable 5 → Opus 5 →
  Fable 5.1.

Verdict: **QUALIFY** — the numbers exist in tech press, but availability
churns faster than a film's shelf life, and "Claude 4.7" misnames the
product. Per the build brief, the film names vendors and approaches, never
point releases, and is retitled "ChatGPT or Claude?". No version number
appears in narration, on-screen text, or metadata. [judgment]

## 4. Claude reads a folder of your files at the start of a session — SUPPORTED

- Claude.ai **Projects** (Pro/Team, since June 2024): chats organized with
  custom instructions and knowledge files that carry across sessions
  (mlq.ai, 2026-03-21).
- **Cowork Projects** (announced by @claudeai 2026-03-20): "Keep your tasks
  and context in one place… Files and instructions stay on your computer";
  attach local folders, custom instructions, scheduled tasks; context
  reusable across sessions without re-establishing folder access
  (vpncentral.com; rssfeeds.cloudsite.builders; healsecurity.com).
- lowcode.agency (2026-09): "persistent instructions and knowledge files
  that carry across sessions" in Desktop Projects; Cowork grants folder
  access for read/edit/create.

The film says: "a folder of files — who you are, what your company does,
how you like things written — and Claude reads them at the start of every
session." Supported. The film does NOT name plan tiers, prices, or the
Cowork research-preview status, so no availability claim is made. [record]
