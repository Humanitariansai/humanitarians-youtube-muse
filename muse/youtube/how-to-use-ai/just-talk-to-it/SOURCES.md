# SOURCES.md — "Just talk to it"

Source: NEW — built from scratch. No mirror-repo source.

Voice-mode availability and icon pattern were verified against these public
sources on 2026-10-03 (see FACTCHECK.md for the claim-by-claim mapping):

1. Anthropic support doc "Use voice mode" (mirrored in
   `harishpiyer/claude-code-docs`, content/support/11101966-use-voice-mode.md):
   mobile (iOS/Android) flow — open the Claude app, tap the voice mode icon
   ("sound wave symbol next to the microphone icon") in the text input field,
   choose a voice, start speaking; hands-free mode (default, responds to
   natural pauses) and push-to-talk mode.
   https://github.com/harishpiyer/claude-code-docs/blob/HEAD/content/support/11101966-use-voice-mode.md
2. Engadget, "How to use Claude's voice mode" (Aug 2026): voice mode on mobile,
   desktop, and web; "tap the black waveform icon in the lower right corner …
   (not the microphone icon right next to it)"; turn-based architecture;
   brief pauses can be misread as the end of a prompt — ask multi-part
   questions one at a time.
   https://www.engadget.com/2231293/how-to-use-claude-voice-mode/
3. Tom's Guide, "Claude's voice mode is now free — here's how to try it":
   sound-wave icon next to the microphone; voice options; speak naturally;
   switch between voice and text anytime, context carries over.
   https://www.tomsguide.com/ai/claudes-free-voice-mode-has-landed-heres-how-to-access-it
4. iTechPost, "How to Use Claude Voice Mode" (Aug 2026): voice-chat uses
   (brainstorming, conversation practice, interview prep); hands-free vs
   push-to-talk; model availability varies by plan.
   https://www.itechpost.com/articles/236986/20260810/how-use-claude-voice-mode-voice-chat-features-voice-mode-models.htm

No other sources. Nothing in the film depends on version-specific UI, pricing,
or model availability, so these sources establish the durable pattern only.
