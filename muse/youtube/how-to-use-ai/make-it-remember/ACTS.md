# ACTS.md — Make it remember (and forget)

Film 24 of the "How to use AI" series. A practical how-to for a general
audience: Claude keeps notes about you now (memory) — here's what belongs
on those notes, what should never be there, and how to check and delete
what it saved.

**Exact title:** Make it remember (and forget)

**Core promise:** By the end, the viewer knows what AI memory is (notes the
AI saves from your chats and reads in new ones), what to store on it (three
kinds of recurring notes, with the keeper test), what never to store
(secrets; sensitive topics off by default; the never-stored categories),
where the notes live (Settings → Memory → Topics), how to edit or delete a
single note, the difference between Pause and Reset, what incognito chats
do, and what memory is *not* (deleting the chat doesn't delete the note;
memory isn't your chat archive).

**Structure:** Three acts.

- Act 1 — the notes (4 beats): the real question (remember what matters,
  forget what doesn't); the three terms (memory / topics / incognito); what
  memory is (the notebook); what to store (the three recurring kinds + the
  keeper test).
- Act 2 — the red lines (3 beats): what never goes in (secrets crossed
  out; sensitive topics off by default; the never-stored list); where the
  notebook lives (Settings → Memory → Topics); fix one note, delete the
  stale one.
- Act 3 — the controls (4 beats): Pause vs Reset (shelved vs emptied for
  good); incognito (the note that never lands); memory is not the chat
  (delete the chat, the note stays); memory is not the archive (two doors
  into your past, two switches).

**Tone:** practical and plain-spoken. Teardown register throughout — short
sentences, no jargon left unexplained. The film teaches one feature and one
habit (check the notebook), not a philosophy of privacy.

**What this film is not:** not a review of any AI product; it does not
assert version-specific UI beyond the verified Settings → Memory → Topics
path; no statistics or prices are quoted; the note-card examples are
illustrations, not claims about what Claude recommends. It does not claim
memory overrides anything or that deleting a topic is retroactive — edits
apply to future chats. It does not conflate memory with chat retention
(incognito chats still exist as chats; they just don't touch memory).

**Source facts:**
- Claude memory: as you chat, Claude saves individual memory topics; the
  whole list sits under Topics in Settings → Memory; each can be read,
  edited, or deleted. Memory is on by default for Free, Pro, Max users.
  (web research 2026-10-04, incl. Engadget's edit-how-to and TechRepublic's
  controls explainer) [record]
- "Include sensitive topics in memory" is off by default (health, race,
  ethnicity, religious beliefs, politics, gender identity); even with it on,
  government ID numbers, SSNs, criminal history, immigration status, and
  acceptable-use violations are never stored. (Anthropic's stated policy via
  BigGo / AndroidAuthority, 2026-10-04) [record]
- Pause keeps stored memories but stops using/creating new ones; Reset
  permanently deletes all stored memories including project memories —
  cannot be undone. (TechRepublic, 2026-10-04) [record]
- Incognito chats don't use existing memory or add new memories; "Search
  and reference chats" is a separate feature with its own setting.
  (TechRepublic, 2026-10-04) [record]
- Updating a stored detail (e.g. a company name) applies to future
  conversations. (Anthropic announcement coverage, iclarified / kucoin,
  2026-10-04) [record]
