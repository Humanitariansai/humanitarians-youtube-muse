# CLAUDE-CODE-RENDER.md — Your personal research assistant

Render instructions for Bear's Mac (Manim + Kokoro). Pre-render package
only: everything except the final MP3/MP4.

## What this package is

- `beat_sheet.json` — 14 beats, 240.0 s total (~4:00), generated by
  `make_sheet.py` (re-run it to regenerate; it asserts the 14-beat
  count, scene↔beat mapping, the ~3–6 min window, the hesitant-writer
  trigger contract, the ≤17-char BDEFS term contract, the BHTF
  prompt-read-in-full contract, and the BOUT outro contract).
- `scenes.py` — 10 Manim scenes (B00_HeroDesk … B09_TheMap), one per
  body beat, show-tell style: one isometric drawing per beat on a cream
  stage, minimal labels, Claude palette (STAGE #F2F0E9, INK #3D3929,
  TERRA #D97757), 16:9. The iso kit is pasted verbatim at the top
  (Gate A copies only `scenes.py`); film helpers follow.
- Narration per beat is in `beat_sheet.json` (`narration_text`);
  on-screen text for each beat is in `shot.visual_intent` and mirrored
  in the matching scene.

## Render steps (run from the film folder on Bear's Mac)

1. `python3 make_sheet.py` — regenerates `beat_sheet.json`, asserts
   pass.
2. Narration: per-beat Kokoro `am_onyx` MP3s from each beat's
   `narration_text` (see `brutalist.art/runtime/scripts/
   generate_audio_kokoro.py`). Audio is the master clock; conform
   scenes to it. BOUT gets a 1.0 s silent tail.
3. Manim: render each scene class, e.g.
   `manim -pqh scenes.py B00_HeroDesk … B09_TheMap`.
4. **Deferred in this VM, REQUIRED here:** run the full layout audit
   `python3 runtime/qc/manim_layout_audit.py scenes.py --curve-strict`
   (needs Manim/pangocairo — unavailable in the build VM) and the
   visual QC pass (frame sampling, 9-point rubric) before calling the
   cut done. Also eyeball label/caption fit (static check doesn't
   measure real text extents) — notably the B09 "a map, not the
   answer" caption and the B02 pile labels.
5. Bookends per show-tell: BIDEA hesitant writer ("Hallo" greeting;
   "do all my research" → "brief my research assistant"), BDEFS terms
   card, BHTF "Your turn." composer (prompt read verbatim, then the
   two checks), BOUT title-restate outro ("Your personal research
   assistant." + "At Nik Bear Brown."; spoken, no jingle).
6. Never publish without Bear's explicit instruction.
