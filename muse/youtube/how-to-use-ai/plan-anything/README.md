## The film

Planning is where AI shines, because it never gets tired of revising. The film
demonstrates the full arc on a weekend trip — constraints first (budget, dates,
interests), then a draft itinerary, then a real revision ("too rushed, slow it
down"), then a packing checklist — and generalizes the pattern
(constraints → draft → revise → checklist) to projects and budgets. It closes
with the one rule that never changes: prices and opening hours go stale, so
the machine plans and you verify.

Built from scratch (no mirror source). The trip is a fictional worked example;
no current prices or availability are asserted. Every technical term
(constraint, draft, itinerary) is defined aloud for a smart, pragmatic general
audience.
