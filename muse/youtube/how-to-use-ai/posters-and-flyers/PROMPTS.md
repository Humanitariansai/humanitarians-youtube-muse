# PROMPTS.md — Posters and Flyers

No generation prompts. All visuals in this film are hand-built Manim
drawings in the show-tell house style; nothing was AI-generated.

The only prompt text in the package is the BHTF "your turn" prompt the
viewer pastes into Claude, which lives in `beat_sheet.json` (BHTF beat,
`ClaudeComposerAsk` props).
