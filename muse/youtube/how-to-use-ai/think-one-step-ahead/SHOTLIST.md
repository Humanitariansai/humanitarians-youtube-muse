# SHOTLIST.md — "Think one step ahead"

One drawing per beat; the voice explains; labels are 1–3 words, beside
objects, never inside an outline. Body beats are all Manim drawings —
**zero cards**, which is a normal, complete show-tell film. (Card test:
every beat's idea is a thing/part/flow from the film's own cast — a page,
a window, words arriving — so each beat is drawn, never carded.)
