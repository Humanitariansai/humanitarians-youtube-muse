# CLAUDE-CODE-RENDER.md — Trust, but verify

Render instructions for Bear's Mac (Manim + Kokoro). Pre-render package
only: everything except the final MP3/MP4.

## What this package is

- `beat_sheet.json` — 10 beats, 266 s total (~4.5 min), generated by
  `make_sheet.py` (re-run it to regenerate; it asserts the 10-beat
  count, scene↔beat mapping, the 3–6 min window, and verdict coverage).
- `scenes.py` — 10 Manim scenes (M01–M10), one per visual beat.
  House palette: INK #111111, PAPER #F7F3EA, ACCENT #B8472F,
  BLUE #2F6BB8, GREEN #2E8B57, GREY #8A8578, CARD #FFFFFF. 1920×1080.
- Narration per beat is in `beat_sheet.json` (`line`); on-screen text
  for each beat is in `screen` and mirrored in the matching scene.

## Render steps (run from the film folder on Bear's Mac)

1. `python3 make_sheet.py` — regenerates `beat_sheet.json`, asserts
   pass.
2. Narration: per-beat Kokoro `am_onyx` MP3s from each beat's `line`
   (see `skills/make/ai-explainer` audio step). Audio is the master
   clock; conform scenes to it.
3. Manim: render each scene class, e.g.
   `manim -pqh scenes.py M01_Bidea … M10_B08Outro`.
4. **Deferred in this VM, REQUIRED here:** run the full layout audit
   `python3 runtime/qc/manim_layout_audit.py scenes.py --curve-strict`
   (needs Manim/pangocairo — unavailable in the build VM) and the
   visual QC pass (frame sampling, 9-point rubric) before calling the
   cut done.
5. Bookends per ai-explainer: cold open on the Claude composer, the
   B07 "Your turn." handoff (prompt read verbatim, then discussed),
   B08 title-restate outro ("Trust, but verify." + @NikBearBrown;
   spoken, no jingle).
6. Never publish without Bear's explicit instruction.
