# You can't beat AI.

A pre-render film package for the humanitarians AI YouTube channel
(https://www.youtube.com/@humanitariansai).

**The film in one breath:** You cannot beat AI at producing work, so stop
competing with it. Outsource the work, never the understanding — write
your constraints, draft first yourself, paste both in, ask for three
versions, pick one and edit it. Two extra minutes of thinking keeps the
machine working for you instead of replacing you.

## Package contents

| File | What it is |
|---|---|
| `beat_sheet.json` | The film: 12 beats, 295 s (~4.9 min), narration lines, visual intent, show blocks. Generated by `make_sheet.py` (do not hand-edit; change the script). |
| `make_sheet.py` | Beat-sheet generator with self-assertions (beat count, scene sequence, bookend acts, narration budgets, speech-floor durations, handoff prompt, verdict-returns-to-open). |
| `scenes.py` | 12 Manim scenes (S01–S12), one per beat; claude-liam skin (cream/ink/terracotta). Static-QC clean: 12 clean · 0 warn · 0 error. |
| `ACTS.md` | Argument, framing, structure, redo notes. |
| `SHOTLIST.md` | Scene-by-scene visual plan; SHOW/HOLD classification; teaching-arc checklist. |
| `FACTCHECK.md` | Claim table with attribution map (method / analogy / illustrative scenario) and the GPS-literature grounding. |
| `SOURCES.md` | Source repo path, research citation, asset/credit notes. |
| `BUILD-LOG.md` | Decisions, failures, fixes. |
| `CHECKS-REPORT.md` | QC gate results per scene class. |
| `PROMPTS.md` | The handoff prompt (verbatim) and build prompts. |
| `CLAUDE-CODE-RENDER.md` | How Bear renders narration (Kokoro am_onyx) and the review/final cut on his Mac. |
